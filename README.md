# 🌌 prykshift's Dotfiles (`mydots`)

Personal dotfiles and system configurations for **Hyprland** with **Caelestia Shell**, paired with customized shells, modern terminals, Neovim IDE setup, launchers, and system monitors.

---

## 📸 Overview & Stack

| Component | Software | Description |
| :--- | :--- | :--- |
| **Compositor** | [Hyprland](https://hyprland.org/) | Dynamic tiling Wayland compositor with smooth animations and custom keybinds |
| **Desktop Shell** | [Caelestia](https://github.com/caelestia-dots/caelestia) | Elegant desktop shell, status bar, drawer launcher, and dynamic theme engine |
| **Session Manager** | [uwsm](https://github.com/Vladimir-csp/uwsm) | Universal Wayland Session Manager |
| **Shell** | `bash` & `fish` | Bash with custom Prykshift fastfetch gradient logo, aliases, fzf, ble.sh |
| **Prompt** | `starship` | Fast, customizable cross-shell prompt |
| **Terminal** | `foot` | Lightweight, blazingly fast Wayland terminal |
| **Editor / IDE** | `neovim` | Custom modular Neovim with Lazy.nvim, Blink.cmp, Treesitter, LSP (Clangd & JDTLS), ToggleTerm Runner |
| **Quick Editors** | `micro`, `zed`, `VS Code` | Micro with keybindings, themed Zed, and VS Code configs |
| **Launchers** | `rofi` & `fuzzel` | Custom Caelestia Rofi theme + Adi1090x applets & power menus; Fuzzel fallback |
| **System Monitors** | `btop`, `htop`, `nvtop` | All themed with cohesive Caelestia palette (CPU/GPU/RAM meters) |
| **Audio Visualizer**| `cava` | Audio visualizer configured for Wayland audio output |
| **Theming & Qt/GTK**| `qt5ct`, `qt6ct`, `gtk-3.0`, `gtk-4.0` | Unified dark/light theme integration via QtEngine & GTK CSS |

## ⌨️ Hyprland Keybindings Cheatsheet

### Applications & Launchers
| Shortcut | Action |
| :--- | :--- |
| `Super` (tap) | Toggle Caelestia drawer / launcher |
| `Super + Space` | Launch terminal (`foot`) |
| `Super + Q` | Launch `vivaldi` (fullscreen) |
| `Super + C` | Launch `code` (fullscreen) |
| `Super + E` | Open file manager (`thunar`) |
| `Super + W` | Close active window |

### Workspaces & Windows
| Shortcut | Action |
| :--- | :--- |
| `Super + [1-9, 0]` | Switch to workspace 1–10 |
| `Super + Left / Right` | Switch to previous / next workspace |
| `Super + Mouse Scroll` | Cycle workspaces (by 10) |
| `Super + Shift + Left / Right` | Move active window to prev / next workspace |
| `Super + Shift + PageUp / PageDn` | Move window to prev / next workspace |
| `Super + Shift + [1-9, 0]` | Move active window to workspace 1–10 |
| `Super + S` | Toggle special workspace |

## ⚡ Neovim Setup Highlights

- **Plugin Manager:** `lazy.nvim`
- **Completion:** `blink.cmp` with Luasnip integration and duplicate filter
- **Syntax & Parsing:** `nvim-treesitter` (C, C++, Lua, Python, Java, Bash, JS/TS, Markdown)
- **LSP Support:**
  - `clangd` for C & C++
  - `jdtls` for Java with dynamic workspace isolation
- **Fuzzy Finder:** `fzf-lua` (`<leader>ff` for files, `<leader>fg` for live grep)
- **Code Execution:** Integrated `<leader>r` runner via `toggleterm` supporting C, C++, and Python
- **Keybindings:**
  - `==` : Format & indent entire file (`gg=G`)
  - `<Alt-Up>` / `<Alt-Down>` : Move selected lines up/down
  - `gd` : Go to definition
  - `K` : Hover documentation
  - `<leader>e` : Show diagnostic floating window

## 🚀 Installation & Restoration

### 1. Clone the repository
```bash
git clone git@github.com:PrikshitGhangas/mydots.git ~/mydots
cd ~/mydots
```

### 2. Run the deployment script
You can choose between creating symlinks (recommended for development) or copying files:

```bash
# Preview what will be deployed without touching existing files:
./install.sh --dry-run

# Interactive install (prompts for link vs copy):
./install.sh

# Or directly specify mode:
./install.sh --link   # Symlink (changes in repository reflect immediately)
./install.sh --copy   # Copy files independently
```

> [!NOTE]
> The `install.sh` script automatically detects any existing configs and backs them up safely to `~/.dotfiles_backup_<timestamp>` before making changes.
